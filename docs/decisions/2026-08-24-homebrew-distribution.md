# Homebrew is the sole plugin distribution channel

## Context

Target audience is macOS developers. Plugins must install without pip or Python knowledge.

## Decision

Plugins ship via a Homebrew formula (generated by `scaffold.sh`). Post-install calls `devflow plugin register`. PyPI and pip are not supported. Out of scope: Linux, Windows.

## Consequences

- `brew install author/tap/plugin` is the full install command
- Authors self-publish to their own tap — no central gatekeeper
- Plugin authors must maintain a Homebrew formula alongside Python code
- macOS only; Linux requires a separate decision

## Implementation Plan

- **Paths**: `devflow-plugin-scaffold/scaffold.sh`, `devflow-plugin-scaffold/scripts/release.sh`, `devflow-sdk/devflow_sdk/plugin/plugin_registry.py` (`PluginEntry.formula`)
- **Follow**: formula post-install calls `devflow plugin register <name> <path>`; `PluginEntry.formula` stores formula name
- **Avoid**: `pip install` in any plugin docs; assuming plugin is on `PYTHONPATH`

### Verification

- [ ] `scaffold.sh <name>` generates a formula that passes `brew audit`
- [ ] Homebrew-installed plugin is discoverable by `PluginLoader.discover(DraftPrPlugin)` without manual setup
- [ ] No `pip` or `pypi` references in scaffold-generated README
